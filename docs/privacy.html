개인정보처리방침

진의 데스크 (Jin Desk) · 시행일 2026-10-03

1. 어떤 데이터에 접근하나요

사용자가 Google 계정 연결을 허용하면 앱은 아래 권한으로 사용자 본인의 데이터에 접근합니다.

  • Gmail (gmail.modify): 받은편지함 메일 목록·제목·미리보기 표시, 사용자가 누른 경우에만 읽음 처리·메일 보내기
  • Google Calendar (calendar.events): 일정 표시, 사용자가 추가하거나 사용자가 켠 자동 추가 기능으로 일정 등록
  • Google Drive (drive.metadata.readonly): 최근 파일의 이름·종류·수정 시각 표시 (파일 내용은 읽지 않음)

2. 데이터는 어디에 저장되나요

모든 처리는 사용자의 맥 안에서 이루어집니다. 로그인 토큰과 화면 표시용 요약은 사용자의 맥(앱 지원 폴더)에만 저장되며, 개발자의 서버나 제3자에게 전송·판매·공유하지 않습니다. 광고나 분석 도구를 쓰지 않습니다.

3. Google API 데이터 사용 제한

이 앱이 Google API로 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

4. 연결 해제와 삭제

앱 메뉴의 “Google 연결 해제”를 누르면 저장된 토큰을 지우고 Google 쪽 권한도 취소합니다. Google 계정 권한 페이지에서도 언제든 취소할 수 있습니다. 앱을 지우고 앱 지원 폴더를 삭제하면 맥에 남은 데이터도 모두 사라집니다.
